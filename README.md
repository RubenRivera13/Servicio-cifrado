# Servicio de Cifrado e Integridad

API REST desarrollada con Node.js y Express que implementa fundamentos de criptografia moderna.

El proyecto demuestra el uso práctico de:

- AES-256-GCM para cifrado autenticado
- SHA-256 para integridad de datos
- bcrypt para almacenamiento seguro de contraseñas
- HMAC-SHA256 para autenticidad e integridad

---

# Tecnologías utilizadas

- Node.js 18+
- Express 4.x
- crypto (módulo nativo)
- bcryptjs
- dotenv
